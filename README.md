# 方块上海 · Block Shanghai

> 方块风格的上海城市漫游：在真实形状的上海里散步、拍照收集景点、坐遍真实的地铁网络。

基于 **Vue 3 + Three.js（WebGPU，自动回退 WebGL 2）+ TypeScript**，纯前端运行。地理和地铁数据来自 OpenStreetMap，离线烘焙成游戏坐标。

**当前阶段：P4 · 地铁第 3、4 层已完成**（真机帧率待确认），下一步 P5 生活与内容（路线图见 [docs/06-roadmap.md](./docs/06-roadmap.md)）

---

## 核心特色（规划）

- 🗺️ **真实城市格局**：黄浦江、苏州河、高架路网、16 个区；市中心 1:1 比例（1km ≈ 200 格），远郊按比例压缩
- 🚇 **真实地铁网络**：1–18 号线、浦江线、磁浮；路线规划和票价；3/4 号线高架上有列车跑；进站、乘车、换乘、选出口出站
- 📷 **拍照收集**：外滩、陆家嘴、豫园等 47 个景点，拍照自动识别并解锁图鉴
- 🌿 **上海生活**：石库门弄堂、梧桐区 Citywalk、沪语路人、小笼生煎、梅雨和四季

## 现在能玩什么（P1–P6）

- 在真实形状的上海里走路：16 个区、黄浦江、苏州河、长江口和崇明岛，主干道和多层高架（含匝道、桥墩）
- 程序化的城市：陆家嘴超高层、石库门弄堂、衡复老洋房、工人新村、远郊村镇；浦西梧桐、浦东香樟
- 第三 / 第一人称，手机上有摇杆；小地图、按区着色的大地图，进入新区弹出区名
- 真实地铁网络：1–18 号线、浦江线、磁浮，416 个车站、1484 个地铁口。查线路图、规划路线（最快 / 少换乘）、按里程计价
- 地铁收集：集站图鉴（按线路分页）、20 条线的线路徽章、11 个地铁成就、每日任务（完成一项 +10 元），在“📖 图鉴”的“地铁”页
- 坐地铁：走到地铁口按 E 进站，站厅刷卡过闸，下到站台等车（倒计时按时刻表），上车逐站行驶、中英文报站，可以跳到下一站或直达；在换乘站走换乘通道，出站按里程扣费，从选定的出口回到街上。磁浮有 300 km/h 的速度屏，浦江线能从车头看前方轨道。着急的话站厅售票机也能“快速到达”
- 看得见的地铁：3/4、5、16 号线等高架上有列车按时刻表运行，高峰更密；高架车站、坡道和隧道口
- 游戏时钟和钱包；昼夜循环，18:30–22:00 外滩、陆家嘴亮灯；天气和季节跟着真实日期（梅雨、台风、雪，梧桐秋天变黄、冬天落叶）；自动存档，三档画质
- 景点：外滩万国建筑群（顺着真实弯度的街墙和江边观景平台）、东方明珠和上海中心（坐观光电梯上去）、豫园九曲桥和城隍庙、陆家嘴三件套和环形天桥、南京路步行街、人民广场、外白渡桥，以及武康大楼、静安寺、新天地、田子坊、中华艺术宫、徐家汇天主堂、龙华寺和龙华塔、南浦大桥、卢浦大桥（电梯上拱顶观光平台）、延安东路立交龙柱、朱家角放生桥（S、A 级共 21 个）；另有 26 个 B 级的区域景点：杨浦大桥和杨浦滨江、1933 老场坊、多伦路、鲁迅公园、北外滩、苏州河和四行仓库、M50、上海火车站、几座公园、西岸、世博、浦东的新场馆，远郊的佘山、七宝、滴水湖、崇明东滩、两座机场枢纽、嘉定孔庙、度假区湖边小镇。一共 47 个，走近会“发现”
- 路人：白领、爷叔、阿姨、学生、游客、外卖骑手、遛狗的人，傍晚公园里跳广场舞，周末人民公园有相亲角；按 E 聊天（上海话带普通话意思），拍照时会转过来一起合影
- 街边小店和文化牌：南京路、豫园、人民广场、陆家嘴、新天地、田子坊有小笼馆、本帮菜馆、早餐摊、手信店、咖啡馆，按 E 逛逛；吃过的美食记进美食图鉴（大闸蟹、青团等按真实季节卖），纪念品放进背包，第一次坐地铁、登东方明珠等还会送纪念品；读文化牌、和爷叔聊天、用月份牌滤镜拍照会解锁文化图鉴。都在“📖 图鉴”的“收藏”页
- Citywalk：武康路—安福路、外滩源—圆明园路—外白渡桥、多伦路—鲁迅公园三条路线，地上有步道、打卡点有路牌，下一站头顶有绿色标记，走完得徽章；沿途咖啡馆收集成“咖啡地图”
- 任务：新手任务（拍东方明珠 → 南京路吃小笼包 → 坐地铁 → 登上海之巅）、7 组区域任务（各区徽章）、主题任务（食在上海、海派文化达人等）、每天 3 个生活任务，在“📖 图鉴”的“任务”页
- 观光巴士、共享单车、出租车：双层敞篷观光巴士从外滩开到静安寺；在马路边按 B 扫一辆共享单车（只能在马路上骑）；按 T 打车去任何一个景点，按里程计价
- 菜单：形象、画质（太卡会自动调低）、全屏（手机上锁横屏）、中文 / English（英文目前覆盖界面和地名）、关于（OSM 署名和致谢）；可以“添加到主屏幕”全屏打开
- 角色形象：“☰ 菜单 → 形象”换肤色、发型、衣服颜色、帽子和眼镜，或者上传一张 64×64 的方块人皮肤
- 黄浦江上的船：东金线、东复线轮渡（2 元）和浦江游览（50 元，十六铺码头出发，夜游最好看），在码头按 E 买票，站在甲板上看两岸
- 拍照：第三人称 / 第一人称 / 自拍，6 种滤镜（老上海月份牌、外滩夜色、梧桐胶片等），自动识别画面里的景点并解锁图鉴；照片存在浏览器本地的相册里，可下载

## 快速开始

需要 Node 22.18+、24 或 26+（Vitest 5 的要求；22.18 起 Node 能直接运行 `.ts` 脚本）。

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 单元测试（Vitest）
npm run typecheck  # 类型检查（vue-tsc）
npm run build      # 类型检查 + 打包，输出 dist/，可直接静态部署
npm run bench      # 渲染基准，需先 npm run dev（见 docs/07 第 4 节）
```

地图数据已经烘焙好放在仓库里。要用最新的 OSM 数据重新生成：先 `brew install osmium-tool`，再 `npm run fetch-osm && npm run bake`，详见 [tools/README.md](./tools/README.md)。烘焙结果可以在 http://localhost:5173/tools/preview/ 俯视检查。

左上角显示当前渲染后端（WebGPU / WebGL 2）和帧率。

## 部署

`npm run build` 生成的 `dist/` 是纯静态文件（相对路径），放到任意静态托管即可。GitHub Pages 的工作流（`.github/workflows/pages.yml`）需要手动触发；国内对象存储的做法见 [07 第 9 节](docs/07-tech-selection.md#9-部署)。

## 项目结构

```
block-shanghai/
├── docs/                    设计文档（从这里开始读）
├── src/
│   ├── engine/              与城市无关的引擎
│   │   ├── Game.ts          主循环、系统调度
│   │   ├── city.ts          城市包契约（类型）
│   │   ├── actors/          玩家、角色外观、输入、跟随相机、路人
│   │   ├── build/           Builder（方块合并 + 碰撞登记）
│   │   ├── geo/             投影、碰撞世界
│   │   ├── map/             2D 地图绘制
│   │   ├── world/           分块流式加载、几何生成、地块、区划
│   │   ├── metro/           地铁线网、时刻表、收集
│   │   ├── interior/        地铁站内场景、乘车流程
│   │   ├── landmarks/       景点加载、远近细节、发现
│   │   ├── transport/       船、观光巴士
│   │   ├── photo/           拍照、滤镜、识别、相册
│   │   ├── life/            小店、文化牌、Citywalk、任务、生活进度
│   │   ├── sky/             昼夜、天气、季节
│   │   └── state/           存档、游戏时钟
│   ├── components/          HUD、地图、各种面板、触屏控件
│   ├── i18n/                界面语言（中文 / English）
│   └── cities/
│       ├── index.ts         城市注册表
│       └── shanghai/
│           ├── config.ts    投影、尺度、区划、OSM 范围
│           ├── buildings.ts 建筑风格和行道树
│           ├── landmarks*.ts S / A / B 级景点
│           ├── content.ts   美食、纪念品、小店、文化图鉴、Citywalk、任务
│           ├── boats.ts / buses.ts / people.ts  船、观光巴士、路人
│           └── data/        OSM 烘焙产物
├── bench/                   渲染基准（WebGPU / WebGL 对比，npm run bench）
├── tools/                   数据烘焙脚本、俯视预览页
└── tests/                   单元测试
```
